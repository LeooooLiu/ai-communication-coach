# Changelog

All notable changes to this project are documented here.

## [Unreleased]

## [0.2.0] - 2026-09-27

### Changed

- Reframed the GitHub introduction around familiar AI communication failures and a before-and-after dialogue.
- Updated the social preview artwork with an experience-led question.
- Added an explicit path for stars, anonymized examples, and behavior reports.
- Classify understanding risk for the next authorized step so evidence gathering is not blocked by a later decision.
- Reconstruct likely intent from explicit wording, active task state, shared decisions, available evidence, and ordinary pragmatic cues.
- Keep shared facts, working interpretations, hypotheses, and unknowns distinct when filling omitted context.

### Added

- Ten anonymized real-conversation evaluation cases and a recorded GPT-6 Luna behavior run.
- A regression case for completing requested discovery before asking a later implementation question.
- Six paired cases for ellipsis, indirect requests, real reference ambiguity, causal hypotheses, hidden motives, and authorization boundaries.
- Goodman and Frank's probabilistic pragmatics framework and Bender and Koller's form/meaning boundary, bringing the traceable theory set to eleven sources.
- A second-model run and a cross-model context-reconstruction report.
- Portable Skill-only Plugin packaging, release policies, English documentation, and reproducible release validation.

## [0.1.0] - 2026-09-27

### Added

- Three-level understanding risk: clear, inferable, and branching.
- Four conversational states: executing, exploring, reflecting, and repairing or changing direction.
- Evidence-based feedback loop for reasoning and expression.
- Multi-turn decision continuity and explicit scope-change handling.
- Attribution between user wording, missing context, AI error, capability limits, and external uncertainty.
- Nine-source theory foundation with a rebuildable local FTS5 corpus.
- Sixteen behavioral evaluation cases.
- Public package validation workflow, contribution templates, and GitHub presentation assets.

# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-27

### Added

- Three-level understanding risk: clear, inferable, and branching.
- Four conversational states: executing, exploring, reflecting, and repairing or changing direction.
- Evidence-based feedback loop for reasoning and expression.
- Multi-turn decision continuity and explicit scope-change handling.
- Attribution between user wording, missing context, AI error, capability limits, and external uncertainty.
- Nine-source theory foundation with a rebuildable local FTS5 corpus.
- Sixteen behavioral evaluation cases.
- Public package validation workflow, contribution templates, and GitHub presentation assets.

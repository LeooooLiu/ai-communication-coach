# Support

Use the channel that matches the request:

- **Unexpected Skill behavior:** open a [behavior report](https://github.com/LeooooLiu/ai-communication-coach/issues/new?template=behavior-report.yml) with a privacy-safe conversation excerpt.
- **Bug or packaging problem:** open a [bug report](https://github.com/LeooooLiu/ai-communication-coach/issues/new?template=bug-report.yml).
- **Idea, usage question, or example:** start a [GitHub Discussion](https://github.com/LeooooLiu/ai-communication-coach/discussions).
- **Security or sensitive privacy problem:** use [private vulnerability reporting](https://github.com/LeooooLiu/ai-communication-coach/security/advisories/new).

Include the installed version, host, model when relevant, expected behavior, observed behavior, and the smallest reproducible example. Remove secrets, personal details, and proprietary project content.
